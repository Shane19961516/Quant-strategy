# Alpha101 US (SPX∪NDX) 入库标准

预测目标：未来 **5** 个交易日收益率（非重叠再平衡）。
股票池：S&P500 ∪ Nasdaq-100；样本起点 2016-08-01。
IC / 分层 / 多空均在非重叠 5 日网格上评估，以避免重叠收益虚高。

## 研究级门槛（实际入库采用）

Alpha101 在美股大盘上的典型 |IC| 仅约 0.5%–1.5%。研究级门槛要求：
显著的 IC t 统计、半样本/年度稳定性、分层单调，且多空净夏普不低于 0。

# 因子入库标准（Admission Standard）

因子须通过以下 **全部** 门禁方可写入因子库（status=`admitted`）。

## 1. 有效性 Validity
- |IC均值| ≥ **0.005**
- |ICIR| ≥ **0.06**
- |IC t| ≥ **1.5**
- 方向校正后 IC 胜率 ≥ **0.51**

## 2. 稳定性 Stability
- 年度子样本 IC 与全样本同号占比 ≥ **0.55**
- 前后半样本 IC 同号（强制）
- 滚动 24m ICIR（方向校正）为正占比 ≥ **0.5**

## 3. 分层检验 Layered
- 分位收益单调性 ≥ **0.5**
- |Top−Bottom 月均价差| ≥ **0.0003**

## 4. 多空检验 Long-Short
- 净夏普 ≥ **0.0**（成本 5.0bp）
- 年化收益 ≥ **-0.01**
- 最大回撤 ≥ **-0.6**（不低于该下限）
- 平均单边换手 ≤ **2.0**

## 5. 样本
- 有效月份 ≥ **36**

## 方向
若 IC 均值为负，入库时 `direction=-1`，读取 API 默认取反，使高分始终对应多头偏好。
