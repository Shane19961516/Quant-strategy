# 趋势 / 套利策略测评框架（防过拟 · 可落地）

## 1. 研报依据（参数冻结，不做全样本寻优）

### 趋势
| 策略 | 文献/业界来源 | 冻结参数 |
|------|----------------|----------|
| TSMOM | Moskowitz-Ooi-Pedersen (AQR)；Baltas-Kosowski | lookback=60d, skip=1 |
| Donchian | Turtle / 经典 CTA 突破 | entry=20, exit=10 |
| Dual MA | 经典 CTA 均线趋势 | fast=20, slow=60 |

### 套利
| 策略 | 来源 | 冻结参数 |
|------|------|----------|
| 跨期价差 | 国内 CTA 套利主流；固定近远月 | z=20, entry=2, exit=0, stop=4；品种 RB/HC/I/CU |
| 产业配对 | 黑色/油脂/化工产业链价差回归 | z=60, entry=2, exit=0, stop=3.5；固定经济对 |
| 布林均值回归 | 短周期统计套利（单品种） | window=20, ±2σ, exit=0, stop=3.5 |

## 2. 防过拟与泛化规则
1. **禁止**在全样本上网格搜参；参数一律文献默认值。
2. **样本划分（预先固定）**：IS=`2018-01-01`–`2021-12-31`，OOS=`2022-01-01`–样本末。OOS 为 headline。
3. **成本**：单边 1.5bp + 滑点 1.5bp（趋势/配对）；跨期近月 0.8bp、远月 2.0bp。
4. **执行**：收盘信号，**次日收益**计入（T+1），无前视。
5. **无杠杆**：组合总名义敞口 ≤ 1× 资金（方向策略等权分仓；套利两腿名义合计 ≤ 资金）。
6. **相关性**：策略日收益两两相关；组合优先低相关袖层。

## 3. 实盘落地检查清单
- 流动性：主力/近月成交与持仓门槛
- 移仓：交割月前强制换月；跨期用固定合约对
- 单腿风险：套利需组合单或腿间对账
- 容量：品种数少、换手低者更易落地
- 制度：保证金、涨跌停、交易日历

## 4. 输出
- 各策略无杠杆净值图
- 等权合成组合净值图
- 业绩表（含 IS/OOS）+ 落地评估
