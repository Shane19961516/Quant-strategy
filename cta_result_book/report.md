# 四策略资金簿报告

- 总资金：1,000,000 元
- 保证金权限：S1 150,000 / S2 300,000 / S3 150,000 / S4 200,000 （合计 800,000）
- 杠杆假设：单边名义 = 保证金 × 10
- 期末权益：887,812 元 （绝对盈亏 -112,188）

## 规则摘要

1. **均线突破**：MA14 上穿 MA16 做多、下穿做空；价格回到中轨 `(MA14+MA16)/2` 平仓；平仓后须新交叉才再开仓
2. **布林带**：20日中轨、±2σ 上下轨；上穿上轨后再下穿上轨做空，下穿下轨后再上穿下轨做多；回中轨平仓；|z|≥4 止损；不重复开仓
3. **相关配对**：全品种滚动20日收益相关>0.6 入选；对数价差20日 z，|z|≥2 回归开仓、回0平仓、|z|≥4 止损；1:1 名义
4. **跨期价差**：分合约按持仓量（缺则成交量）取当日主力/次主力；价差=主力−次主力；20日 z，|z|≥2 回归、回0平、|z|≥4 止损
