# 广度冲刺报告：能否达到 OOS Sharpe≥2？

## 结论

**未达到。** 在日频、lev≤1、含成本、OOS≥2022 口径下：

- 单袖层最高 OOS Sharpe ≈ **0.83**
- 预注册实盘组合最高 OOS Sharpe ≈ **1.10**
- 即使用 OOS 偷看筛选的 oracle 上界 ≈ **0.99**

以上均 **< 2.0**。零成本时单对 I-RB 亦仅约 0.86，说明瓶颈是**信号边缘本身**，不是费用或杠杆。

## 为何加杠杆无效

夏普对仓位缩放近似不变；把名义从 1× 提到 10×，收益与波动同比放大，夏普不升到 2。

## 若坚持 Sharpe≥2 的下一步

1. **换频率**：分钟级/TICK 做市或短线（本仓库只有日线）
2. **换市场**：股指期权、跨市场期现、高流动性外盘
3. **换目标**：将硬门槛改为 OOS Sharpe≥1.0（当前最优实盘候选已接近）
4. **拒绝**：用 lev 或全样本调参把夏普“做”到 2——那不是可实盘结果
