# 收益目标缩放报告（目标年化 15–20%）

## 结论

**推荐：`target_vol12`**

- OOS CAGR ≈ **18.1%**（目标带 15–20%）
- OOS Sharpe ≈ **1.45**（与无杠杆书接近）
- OOS 年化波动 ≈ **12.7%**
- OOS MaxDD ≈ **-9.2%**
- WF 均值夏普 ≈ **1.25**

- 因果目标波动；OOS 平均杠杆 ≈ **11.0×**，P95 ≈ **16.6×**

无杠杆 live_v3 夏普尚可但 CAGR 过低，是因为等权+lev≤1 把组合波动压到约 1%。要 15–20% 年化，必须放大名义（期货保证金杠杆），夏普不会因此升到 2。
