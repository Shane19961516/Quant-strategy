# live_v4 稳定书：修复前半段无收益

## 问题

live_v3 + 目标波动后 OOS CAGR≈18%、Sharpe≈1.45，但 **2018–2020 基本走平/略亏**：等权稀释空仓袖层，且 `pair_I_RB` 前半段大幅拖累（IS Sharpe≈−0.54）。这不是杠杆问题，是**书的时段稳定性问题**。

## 修复

1. 剔除 IS 不合格袖层（尤其 `pair_I_RB`）
2. 预注册 IS Sharpe≥0.25：RB-HC / cal_HC / cal_I / carry / olsx_RB_HC
3. 活动感知配资，避免 2018 carry/跨期未激活时被 0 收益袖层稀释
4. 可选 DualMA 压舱；再套因果目标波动≈12%

## 推荐：`v4_core_eq_tv`

- 成员：`pair_RB_HC, cal_HC, cal_I, edge_carry_xs, edge_olsx_RB_HC`
- 2018–2020：Sharpe **0.42**，CAGR **5.1%**，MaxDD **-16.7%**
- IS：Sharpe **0.65**，CAGR **8.3%**
- OOS：Sharpe **1.26**，CAGR **15.1%**，MaxDD **-11.5%**，vol **12.6%**
- WF 均值夏普 **1.19**
