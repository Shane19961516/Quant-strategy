# 因子入库标准（Admission Standard）

因子须通过以下 **全部** 门禁方可写入因子库（status=`admitted`）。

## 1. 有效性 Validity
- |IC均值| ≥ **0.02**
- |ICIR| ≥ **0.3**
- |IC t| ≥ **2.0**
- 方向校正后 IC 胜率 ≥ **0.55**

## 2. 稳定性 Stability
- 年度子样本 IC 与全样本同号占比 ≥ **0.75**
- 前后半样本 IC 同号（强制）
- 滚动 24m ICIR（方向校正）为正占比 ≥ **0.55**

## 3. 分层检验 Layered
- 分位收益单调性 ≥ **0.6**
- |Top−Bottom 月均价差| ≥ **0.003**

## 4. 多空检验 Long-Short
- 净夏普 ≥ **0.3**（成本 20.0bp）
- 年化收益 ≥ **0.0**
- 最大回撤 ≥ **-0.5**（不低于该下限）
- 平均单边换手 ≤ **1.8**

## 5. 样本
- 有效月份 ≥ **36**

## 方向
若 IC 均值为负，入库时 `direction=-1`，读取 API 默认取反，使高分始终对应多头偏好。
