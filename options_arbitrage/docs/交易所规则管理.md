# 交易所规则管理（v2.0.0）

> 规则包版本：`margin_rules-v2.0.0` · 核验日期：2026-08-20

## 1. 规则文件

| 文件 | 用途 |
|------|------|
| `config/margin_rules.json` | 单腿/组合保证金系数 |
| `config/product_specs.json` | 合约乘数、交易所 |
| `config/tick_sizes.json` | 最小变动价位 |
| `config/rules_meta.json` | 来源、核验日期、组合认定说明 |

## 2. 单腿卖出保证金（国内商品期权）

```
Margin_leg = Premium_settle + max( F×mult×rate − 0.5×OTM_cash , 0.5×F×mult×rate )
```

- `Premium_settle` = 权利金价格 × 乘数（现金）
- `OTM_cash` = 虚值额 × 乘数
- `rate` = 标的期货保证金比例（品种/交易所配置）

**来源**：大商所/郑商所/上期所公开规则摘要；具体比例以当日交易所通知为准。

## 3. 组合保证金

- **理论组合**（交易所支持宽跨认定时）：`max(M_call, M_put) + Premium_OTM_leg`
- **无优惠合计**：`M_call + M_put`（组合认定不明确或客户未开通时**按此评级**）
- **客户预计**：交易所理论值 × 期货公司加收（默认 **未知** → 报告不得称“实际占用”）

## 4. 组合认定状态

| 状态 | 处理 |
|------|------|
| `confirmed` | 可使用理论组合保证金 |
| `unclear` | 仅报告无优惠合计 + 理论值（标注待核验） |
| `unsupported` | 仅报告无优惠合计 |

当前默认：**unclear**（宽跨组合保证金依品种/席位开通情况而异）。

## 5. 行权与到期

- 美式行权：深度实值临近到期需监控提前指派。
- 到期日估算：交割月前第 5 个日历日（遇休市顺延）——**近似**，下单前核对交易所日历。

## 6. 变更流程

1. 更新 `margin_rules.json` / `tick_sizes.json`
2. 更新 `rules_meta.json` 中 `verified_date` 与 `changelog`
3. 重跑扫描；报告自动引用 `rules_version`
