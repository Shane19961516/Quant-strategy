## 大商所 (DCE) 数据访问说明

### 问题

`ak.option_hist_dce` 直接 POST `http://www.dce.com.cn/dcereport/.../dayQuotes` 会返回 **HTTP 412**（瑞数 JS WAF）。云环境无法用裸 `requests` 拉到期权日行情。

### 方案

本仓库实现 `data_fetcher/dce_client.py`：

1. 用 **Playwright Chromium** 打开 `www.dce.com.cn` → 频道页，完成 WAF Cookie / JS 签名
2. 在页面上下文内 `fetch("/dcereport/publicweb/dailystat/dayQuotes")`（自动带 WAF 查询参数）
3. 会话复用，扫描全品种时只暖机一次

依赖：`playwright`（见 `requirements.txt`），首次环境需：

```bash
pip install playwright
python -m playwright install chromium
```

### 覆盖品种

聚丙烯 / 聚乙烯 / PVC / 棕榈油 / 玉米淀粉 / 鸡蛋 / 生猪 / 原木  
（豆粕、玉米等已在新浪链路上有实时买卖盘，优先走 Sina。）

### 口径

DCE 日线为**结算价 + 交易所 IV**，无实时买卖盘 → 硬闸门 `live_bid_ask_book` 失败，最高分类为**观察**，不可进**推荐**。
