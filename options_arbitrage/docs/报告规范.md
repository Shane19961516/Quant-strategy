# 报告规范（v2.0.0）

> 模板版本：`report-v2.0.0`

## 1. 报告定位

- 输出对象：**下一交易日候选**（Next Session Candidates），非“收盘可立即成交”。
- 标题必须包含：`下一交易日候选 · 数据截止 {timestamp}`。

## 2. 元数据块（必填）

```yaml
report_version: report-v2.0.0
methods_version: methods-v2.0.0
rules_version: margin_rules-v2.0.0
data_source: <来源>
quote_asof: <ISO8601>
target_session: <下一交易日 YYYY-MM-DD>
model: Black-76 (American risk flagged)
account_equity: null | number
```

## 3. 分类

| 分类 | 条件 |
|------|------|
| **推荐** | 全部数据闸门通过 + 评分达标 + 事件可接受 + 压力/预算通过 |
| **观察** | 策略逻辑可能成立，但报价/IV历史/客户保证金/账户信息等有缺失 |
| **排除** | 硬性风险、不可成交、到期异常、模型无效、压力失败 |

**禁止**为凑数量放宽硬性条件。无合格候选须写：**今日无推荐**。

## 4. 表格字段（候选明细）

- 品种、期权月份、对应标的期货、DTE
- 卖 Call/Put 合约、行权价、买一价、卖一价、中间价、滑点
- IV（反解）、Δ、Γ、Θ、Vega
- 固定期限 ATM IV、IVR、IVP、HV30、VRP、Skew25
- 技术面评分及分量
- 权利金收入（买一）、手续费（如有）、单腿保证金、无优惠合计、理论组合、客户预计（或 N/A）
- 盈亏平衡、风险中性到期盈利概率、历史触及率
- 压力：IV+50%、标的±3%、组合优惠失效（无优惠合计）
- 闸门通过/失败列表、分类理由

## 5. 风险段（必填）

- 收益限于净权利金；尾部无限/极大
- 负 Gamma、负 Vega 在趋势+IV 上升时双重恶化
- 涨跌停/跳空、组合优惠失效、产业链共振
- **入场前须重新核验实时价格与保证金**

## 6. 输出文件

- `output/next_session_report.md`
- `output/next_session_scan.json`（含完整追溯字段）
