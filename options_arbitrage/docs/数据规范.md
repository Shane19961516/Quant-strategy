# 数据规范（CSV / Excel 快照）

当网络行情不足或需离线复现时，提供以下文件。**禁止**把缺失字段填 0。

## 1. 固定期限 ATM IV 历史

路径：`data/iv_history/{PRODUCT}_atm30.csv`

| 列 | 说明 |
|----|------|
| date | YYYY-MM-DD |
| atm_iv | 小数（0.22）或百分数（22）；>3 视为百分数 |

导入：

```bash
python scripts/seed_iv_history.py --import-csv SR=./my_SR_atm30.csv
```

## 2. 盘口快照目录（`--csv-dir`）

```
snapshots/YYYYMMDD/
  meta.json
  SR_futures.csv
  SR_chain.csv
```

`meta.json` 示例见 `data/fixtures/snapshot_meta.example.json`。

`*_chain.csv` 必填：`strike,call_bid,call_ask,put_bid,put_ask`（可选 call_oi/put_oi/符号）。买一或卖一缺失则该腿不可用，闸门失败。

`*_futures.csv` 必填：`date,open,high,low,close`（可选 settle）。

## 3. 账户参数

推荐级必须提供：

```bash
python run_e2e.py --equity 500000 --client-margin-addon 0.05
```
