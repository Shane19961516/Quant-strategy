## 4. 风险提示与交易建议

1. **收益有限、风险巨大**：卖出宽跨最大盈利为收取的权利金，标的单边大幅波动时亏损可迅速扩大。
2. **仓位**：单品种保证金占用建议不超过总资金的 20–30%；账户总占用建议 < 60%。
3. **止损**：权利金上涨 50–100%，或标的突破建仓时震荡区间、IV 继续攀升时，优先减仓/平仓。
4. **美式提前行权**：国内商品期权多为美式，深度实值时存在被提前行权风险。
5. **夜盘与外盘**：贵金属、原油、有色等需警惕隔夜外盘跳空；事件窗口建议空仓或轻仓。
6. **保证金优惠**：组合保证金规则可能调整，下单前以期货公司试算为准。
7. **替代结构**：若担心尾部风险，可用铁鹰式（Iron Condor）买入更虚值期权保护。
