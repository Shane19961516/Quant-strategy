# UPV 策略说明书（第一阶段实现版）

> 对应代码：本目录  
> 回测产物：`reports/`  
> 日期：2026-09-16

这份文档写的是**现在代码里真正在跑的策略**，不是规格里尚未实现的部分。核心原则：只用 OHLCV，不做宏观、新闻、财报、机器学习。

主链路：

```text
Yahoo 1h OHLCV
→ 清洗、UTC 对齐、落 Parquet
→ 标准化量价特征（窗口 24 根）
→ 四状态 Regime（趋势 / 震荡 / 冲击 / 过渡）
→ 模型 A–E / SCORE 给出方向脉冲
→ 下一根开盘成交
→ 按 ATR 止损距离做风险预算仓位
→ 止损 / 跟踪止盈 / 时间止损 / 反向信号离场
→ 多品种净值逆波动合成等风险组合
```

当前主推模型是 **B**（趋势 + 突破 + 放量确认）。组合层再按日历年化 27% 做研究杠杆映射。

## 2. 如何处理数据

代码：`universal_quant/adapters/yahoo.py`、`brent_quant/data_loader.py`、`brent_quant/data_cleaner.py`。

### 2.1 下载

1. `yfinance.download(ticker, period, interval=1h, auto_adjust=False)`  
2. 失败则 `Ticker.history`  
3. 再失败则直连 `query1.finance.yahoo.com/v8/finance/chart/...`  
4. 若 `730d` 为空，依次降级 `60d`、`1y`

列名扁平化规则：只保留一套 `open/high/low/close/volume`；跳过 `adj_close`、分红、拆股。

### 2.2 时间对齐

```text
若无时区 → 按 America/New_York 本地化
→ 转到 UTC
→ 按时间排序
→ 同一时间戳留最后一条
```

### 2.3 清洗（`clean_ohlcv`）

| 步骤 | 做法 |
|---|---|
| 缺 OHLC | 整根丢掉，**不**前向填充价格 |
| 重复时间戳 | 留 last |
| 成交量空值 | 填 0，零成交 K 线保留 |
| 非法 K 线 | `high < low`、价格 ≤ 0、high 低于 open/close 等，打标不删 |
| 异常收益 | `\|Δclose\| > 10%` 打标，供质检，策略仍用这根 K |
| 缺棒 | 间隔大于 1 根、小于 1 小时才算缺失；周末/休市缺口不算 |

清洗后策略只用五列：`open, high, low, close, volume`。

### 2.4 防未来函数（全链路）

- 突破轨道用 **过去 N 根** 的 high/low：`high.shift(1).rolling(N).max()`，当前 K 不进窗口。
- 信号在 **K 线收盘** 计算，成交在 **下一根开盘**。
- 仓位、止损用进场当时的 ATR/NATR，不偷看后面的波动。

## 3. 标准化特征

代码：`universal_quant/features/`。默认窗口 **N = 24**（1h 上约 1 个交易日；近 24h 交易的期货/BTC 则是一天）。

所有跨品种比较都用 **比率 / z-score / ATR 归一化**，不用原始成交量、不用美元波动。

### 3.1 趋势

**效率比 ER**（Kaufman）：

\[
ER_t = \frac{|C_t - C_{t-N}|}{\sum_{i=0}^{N-1} |C_{t-i} - C_{t-i-1}|} \in [0,1]
\]

ER 高 = 价格走得直；ER 低 = 来回磨。

**对数斜率**：对 \(\ln C\) 做过去 N 根的 OLS 斜率，尺度近似与价格无关。

### 3.2 动量

\[
momentum_t = C_t / C_{t-N} - 1
\]
\[
momentum\_score_t = momentum_t / RV_t
\]

\(RV\) 是过去 N 根收益率标准差。除以波动后，SPY 和 BTC 才能放在同一量纲比较。

### 3.3 波动

真实波幅：

\[
TR_t = \max(H_t-L_t,\; |H_t-C_{t-1}|,\; |L_t-C_{t-1}|)
\]
\[
ATR_t = MA_N(TR),\quad NATR_t = ATR_t / C_t
\]

另外还有：实现波动 \(RV\)、波动 z-score \(vol\_z\)、收益 z-score \(ret\_z\)、波动归一化收益。

### 3.4 突破（Donchian，不含当前 K）

\[
HH_t = \max(H_{t-N},\ldots,H_{t-1}),\quad LL_t = \min(L_{t-N},\ldots,L_{t-1})
\]

- 多头突破：\(C_t > HH_t\)
- 空头突破：\(C_t < LL_t\)
- 强度：\(\text{breakout\_strength} = (C_t - \text{轨道}) / ATR_t\)

### 3.5 成交量（禁止直接比原始 volume）

\[
volume\_ratio = V_t / MA_N(V)
\]
\[
volume\_z = (V_t - MA_N(V)) / STD_N(V)
\]
\[
signed\_volume = \mathrm{sign}(\Delta C_t)\cdot V_t
\]
\[
volume\_momentum = \sum signed\_volume \text{（N 根）}
\]

### 3.6 K 线结构

- `body_ratio`：实体 / 全幅
- `clv`：收盘在高低点中的位置，\([-1,1]\)
- `range_ratio`：本根振幅 / 平均振幅（压缩/扩张）
- `range_position`：收盘在过去 N 根轨道中的相对位置，\([0,1]\)

## 4. 市场状态（Regime）

代码：`universal_quant/regimes/regime_engine.py`。优先级：**冲击 > 趋势 > 震荡 > 过渡**。

| 状态 | 判定 |
|---|---|
| **shock** | `\|volume_z\|≥2.5` **或** `\|ret_z\|≥3.0` **或** `\|vol_z\|≥2.5` |
| **trend** | 非冲击，且 `ER≥0.50` 且 `\|momentum_score\|≥0.50` |
| **range** | 非冲击，且 `ER≤0.30` 且 `\|momentum_score\|<0.50` |
| **transition** | 其余 |

趋势方向 `trend_dir = sign(momentum_score)`。

冲击优先的原因：放量暴涨暴跌时，趋势规则容易追在最差的位置。

## 5. 如何产生信号

代码：`universal_quant/strategies/selector.py`、`score.py`。

信号是 **方向 × 强度**，取值在 \([-1, 1]\)。  
**A–E 和 BO 是脉冲**：大多数 K 线信号为 0。引擎见到非零才开仓，然后拿到止损 / 反向 / 时间止损才平，**不会因为信号回到 0 就平仓**。  
**SCORE 是粘性目标**：分数掉到阈值以下会主动减仓、打平。

冲击状态下，所有模型的仓位再乘 `SHOCK_SIZE = 0.35`。

### 5.1 趋势跟踪（Trend Following）

同时满足才发脉冲：

**做多**

1. `trend_dir > 0`（动量为正）
2. 收盘突破过去 24 根最高价
3. `momentum_score > 0`

**做空** 对称。

若 `use_volume=True`（模型 B/D/E），还要 `volume_ratio ≥ 1.2`（放量确认）。没有放量就不开。

### 5.2 均值回归（Mean Reversion，模型 E 在震荡市用）

- 做多：`range_position ≤ 0.15` 且 `volume_ratio < 1`（缩量、靠近下轨）
- 做空：`range_position ≥ 0.85` 且缩量

### 5.3 模型矩阵

| 模型 | 规则 | 引擎行为 |
|---|---|---|
| **A** | 趋势跟踪，不看量 | 脉冲持有 |
| **B** | 趋势跟踪 + 放量 | 脉冲持有（主推） |
| **C** | A，但只在 `trend` 状态开 | 脉冲持有 |
| **D** | B，但只在 `trend` 状态开 | 脉冲持有 |
| **E** | 趋势市用 B；震荡市用均值回归；冲击市除非 `\|breakout_strength\|>1` 否则不开；过渡市用 `0.5 × B` | 脉冲持有 |
| **SCORE** | 综合分映射成 ±1 / ±0.5 / 0 | 跟随目标，可主动打平 |
| **BO** | 纯突破，对照用 | 脉冲持有 |
| **BHS** | 买入持有，对照用 | 无交易 |

C/D 在这段偏牛的样本里过滤过严，交易次数和收益都明显下降。SCORE 在商品和 BTC 上过度交易、净亏损。第一阶段筛选后主模型是 **B**。

### 5.4 综合评分 SCORE（仅 SCORE 模型）

把特征压到 \([-1,1]\) 后加权，输出 \([-100, 100]\)：

| 分量 | 权重 | 含义 |
|---|---:|---|
| 带方向的 ER | 20 | 趋势是否干净 |
| 动量分数 / 3 | 20 | 波动归一化动量 |
| 突破强度 / 2 | 20 | 突破是否够深 |
| 放量确认 | 15 | `volume_ratio-1`，方向跟突破/动量走 |
| 波动惩罚 | 10 | `-vol_z/3`，波动膨胀减分 |
| CLV | 10 | 收盘位置 |
| 压缩 | 5 | 窄幅 + 方向性收盘 |

映射：

- `score ≥ 60` → +1  
- `score ≥ 30` → +0.5  
- `score ≤ -60` → −1  
- `score ≤ -30` → −0.5  
- 其余 → 0

### 5.5 从信号到成交（防未来）

对第 \(t\) 根 K：

1. 用第 \(t\) 根 **收盘** 算出信号，先放进 `pending`
2. 第 \(t+1\) 根 **开盘** 才开仓或反手
3. 进场价 = 开盘价 ± 1 tick 滑点
4. 同一根 K 内先处理挂单，再检查止损，再按收盘盯市

因此回测不会在「已经知道收盘突破」的同一根 K 里成交。

## 6. 风险管理

代码：`universal_quant/backtest/engine.py`。

每笔交易同时受四道闸：固定 ATR 止损、跟踪止盈、时间止损、反向脉冲。**没有** 组合层相关性发剪、行业限额、日亏损熔断（规格有，第一阶段没做）。

### 6.1 固定止损

进场后：

\[
stop = fill - side \times 2 \times ATR
\]

`side = +1` 多，`−1` 空。`STOP_ATR_MULT = 2.0`。

盘中：多头 `low ≤ stop`、空头 `high ≥ stop` 即按止损价离场（同样加 1 tick 滑点）。

### 6.2 跟踪止盈

记录持仓以来的极值（多头最高价 / 空头最低价），

\[
trail = extreme - side \times 3 \times ATR
\]

多头止损只上移、空头止损只下移（`TRAIL_ATR_MULT = 3.0`）。趋势走出来后，离场主要由跟踪止盈完成，而不是时间止损。

### 6.3 时间止损

持仓满 **72 根** 1h K（约 3 个交易日，近 24h 品种则约 3 个自然日）仍未触发止损，按当根 **收盘** 离场。

实测模型 B 平均持仓大约 12–16 根，绝大多数在时间止损前就被 ATR 止损/跟踪带走。把 24 改成 72，主要是给少数长趋势留空间，不是让每笔都拿到 72 小时。

### 6.4 反向信号

脉冲模型持仓期间，只有出现 **反方向非零脉冲** 才会平仓再反手。信号变回 0 继续拿。

这是为了避免「粘性目标在止损后立刻按原方向再开」把交易次数打到上千笔。

### 6.5 冲击降仓

`regime == shock` 时，信号强度乘 0.35，再进入仓位公式。模型 E 在冲击里还额外要求突破强度绝对值 > 1，否则直接不开。

### 6.6 单笔亏损预算

仓位公式保证：若价格走到 2×ATR 止损，亏损大约等于 `RISK_PER_TRADE × NAV`（目前 1.0%），再乘信号强度。详见下一节。

## 7. 仓位管理

代码：`universal_quant/portfolio/sizing.py`。

### 7.1 单笔权重

\[
w = \mathrm{clip}\left(\frac{r}{k \times NATR}\times |s|,\; 0,\; w_{max}\right)
\]

| 符号 | 默认 | 含义 |
|---|---:|---|
| \(r\) | 1.0% | 单笔风险预算，相对当前 NAV |
| \(k\) | 2.0 | 止损 ATR 倍数 |
| \(NATR\) | ATR/收盘价 | 一跳止损的百分比距离 |
| \(s\) | 0.35 / 0.5 / 1.0 | 信号强度（冲击、过渡、满仓） |
| \(w_{max}\) | 2.5 | 名义权重上限（可加杠杆） |

例：某品种 `NATR = 0.4%`，满仓信号：

\[
w = 0.01 / (2 \times 0.004) = 1.25
\]

即名义仓位 125% NAV。若 `NATR` 小到算出 \(w>2.5\)，砍到 2.5。`NATR` 无效则不开。

直觉：波动大的品种（BTC）自然仓位小，波动小的品种（SPY）仓位大，**每笔在止损处亏掉的钱大致一样**。这就是「按风险而不是按金额」分配。

### 7.2 账户记账

- 初始 NAV = 1,000,000  
- 仓位用 **权重 × NAV** 的收益百分比盯市，不是下真实期货张数  
- 合约乘数写在元数据里，回测记账目前按价格收益率 × 权重，不把 1000 桶/手再乘进去（避免和 Yahoo 连续价重复放大）

### 7.3 成本

进出场都扣：

\[
\mathrm{cost} = |w| \times NAV \times \left(\frac{\text{commission bps}}{10^4} + \frac{\text{slip ticks}\times tick}{price}\right)
\]

默认滑点 1 tick。BTC 4 bps，股票 1 bps，期货 1.5 bps。

### 7.4 等风险组合

代码：`universal_quant/portfolio/risk_budget.py`。

单品种跑完后，用各品种 **日频策略净值** 合成组合：

1. 对齐到 **交易日**（去掉周末 BTC，避免 252 日年化被日历天数稀释）
2. 对日收益算波动 \(\sigma_i\)
3. 逆波动权重 \(w_i = (1/\sigma_i) / \sum(1/\sigma_j)\)，**和为 1**
4. 组合日收益 = \(\sum w_i r_{i,t}\)

最近一次模型 B 的权重大约：

| 品种 | 权重 |
|---|---:|
| QQQ | 25.7% |
| SPY | 25.2% |
| Brent | 17.1% |
| BTC | 16.7% |
| Gold | 15.3% |

波动低的腿权重大。这里用的是全样本波动，属于研究合成，不是滚动再平衡的实盘组合。

### 7.5 目标年化（研究杠杆）

未加杠杆的 B 组合日历年化约 19.9%、Sharpe 约 3.75。为落到 25–30% 目标带，对组合日收益乘一个常数杠杆 \(L\)，使日历年化 = **27%**，并加两道帽：

- 组合年化波动 ≤ 12%
- \(L\) ≤ 8

当前 B 组合 \(L \approx 1.32\)，波动约 6.2%，回撤约 −2.4%。  
这是 **全样本反推**，会用到未来波动；实盘应改成滚动窗口估 \(L\)，不能把 27% 当年保证。模型 D 的 Sharpe 不够，波动顶到 12% 也到不了 25%。

规格里还有相关性发剪、风险簇限额、Kill Switch，第一阶段 **没有实现**。

## 8. 一条交易的完整例子

以模型 B、SPY 为例。

1. 第 t 根 1h K 收盘：`ER` 高、`momentum_score>0`、收盘高于过去 24 根最高价、`volume_ratio≥1.2` → 脉冲 `+1`。
2. 第 t+1 根开盘买入。假设 `NATR=0.35%`，则  
   \(w = 0.01 / (2\times 0.0035) \approx 1.43\)（143% NAV）。
3. 初始止损 = 开盘成交价 − 2×ATR；之后随新高把止损抬到「最高价 − 3×ATR」。
4. 持有期间模型 B 再出同向脉冲 **不加仓**；出现空头脉冲则平多开空。
5. 触发止损、满 72 根、或样本结束，则平仓。

## 10. 第一阶段明确没做

- 付费行情、真实合约换月、持仓量  
- 滚动波动目标、相关性发剪、风险簇限额  
- 券商实盘下单  
- Walk-forward / 参数网格（只有离线单测 + 一次 730d 回测）  
- 机器学习、宏观、基本面  

策略能迁移到别的品种，靠的是 **标准化特征 + 状态切换 + 按风险配仓**，不是某一条均线对所有市场都有效。
